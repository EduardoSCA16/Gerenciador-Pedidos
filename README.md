# Gerenciador de Pedidos

Projeto criado para praticar persistência de dados utilizando Java, Spring Boot, JPA e PostgreSQL.

---

O objetivo é trabalhar com entidades como `Produto`, `Categoria` e `Pedido`, aplicando mapeamento de tabelas, geração de IDs, configuração de colunas e persistência de dados no banco.

Projeto desenvolvido durante meus estudos de Spring Data JPA.
